# Timed task worksheet

Make a private local copy per preregistered participant and task. Do not commit actual responses or receipts. Local fixture attempts must be marked **simulated**. Real trials require the separate approved protocol, supported-client receipt and security review. Record the initial failure before any repair; do not swap participants.

Stop timing only after the useful response, not when a URL appears. Include active work on login and consent. Record passive waiting and elapsed wall time as well, so active timing cannot hide a long email wait. “60 seconds” is an exploratory question; the frozen E2 rule remains ≤300 active seconds and ≤half the strongest viable alternative.

For the synthetic exercise, reset the fixture, start the clock, read the allowed result, try wrong caller and ungranted operation, revoke, then request again. Reset before testing offline. A denied request must not increment the fixture's operation count. None of these checks establishes actual OAuth, security, revocation latency, demand or payment.
