01

Install and sign in

curl -fsSL https://tunn.to/install.sh | sh
tunn login

Intel or ARM. The downloader verifies the latest release from https://tunn.to/dl; manual downloads are on GitLab releases. If tunn is not found, add $HOME/.local/bin to PATH. For source builds and recovery, see the install guide.

02

Share port 3000

# only you
tunn 3000
# one person, or everyone at a domain
tunn 3000 --allow=alex@example.com
tunn 3000 --allow=@example.com
# anyone with the link
tunn 3000 --public

The CLI prints the HTTPS URL. Invited people sign in with GitHub or an email link; everyone else gets a 403 at the edge, before anything reaches your app. For public webhooks, verify signatures at the edge and keep your app's own check on.

03

Watch requests and usage

tunn 3000 --public --inspect
tunn usage

The local inspector stores headers, not bodies, unless you add --inspect-body. Your account also has a request inspector. Quotas cover all your endpoints and reset monthly in UTC. At a limit, tunn stops; there are no overage charges. Plans and units

04

Connect a local MCP server

tunn mcp -- ./my-mcp-server

MCP endpoints are private by default. Copy the printed /mcp URL into your client, sign in and approve access. Full walkthrough

05

Coming from ngrok

# ngrok http 3000
tunn 3000 --public
# ngrok http 3000 --subdomain=work
tunn 3000 --name=work --public

Run tunn login instead of setting an authtoken. ngrok domains, config files and traffic policies do not carry over. Free keeps one name, Pro keeps ten, random names included. tunn vs ngrok
