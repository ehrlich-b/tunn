Get your local server online

Use tunn for local MCP tools, webhook tests and app previews. Your local process must stay running.

1. Install and sign in

curl -fsSL https://tunn.to/install.sh | sh
tunn login

macOS/Linux on Intel or ARM. The downloader verifies the latest release from https://tunn.to/dl; manual downloads are on GitLab releases; for checked source builds and recovery, use the install and recovery guide. If tunn is not found, add $HOME/.local/bin to PATH.

See Docker client setup and status measurements.

2. Expose a port

tunn http 8080

Web tunnels are owner-only by default. Add --allow=alice@example.com to invite someone by email. For anonymous access or webhooks, run tunn http 8080 --public and configure edge signature verification. Keep your application's signature verification enabled.

3. Connect a local MCP tool to Claude.ai

tunn mcp -- ./my-mcp-server

MCP endpoints are private by default. Copy the printed /mcp connector URL, sign in and approve access. Follow the complete tutorial.

Coming from ngrok?

# ngrok http 8080 →
tunn http 8080 --public
# ngrok http 8080 --subdomain=work →
tunn http 8080 --subdomain=work --public

This is an HTTP command shortcut, not full ngrok compatibility. Run tunn login instead of configuring an ngrok authtoken. ngrok --domain, config files and traffic policies do not transfer. Free attempts to reserve one published name; Pro attempts up to ten, including random names. Choose names before publishing. Compare the tradeoffs.

Inspect webhooks and watch usage

tunn http 8080 --public --inspect
tunn usage

The local inspector omits bodies by default. Quotas apply across all account endpoints and reset monthly in UTC. Check your account or plans and exact usage units before upgrading. No automatic overage charges.
