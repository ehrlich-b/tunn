Get your local server online

Use tunn for local MCP tools, webhook tests and app previews. Your local process must stay running.

1. Install and sign in

curl -fsSL https://tunn.to/install.sh | sh
tunn login

macOS/Linux on Intel or ARM. The downloader follows the latest GitHub release; for checked source builds and recovery, use the install and recovery guide. If tunn is not found, add $HOME/.local/bin to PATH.

2. Expose a port

tunn http 8080

The printed HTTPS URL is public. Add --allow=alice@example.com for interactive email sharing. For webhooks, use --public and configure edge signature verification. Keep your application's signature verification enabled.

3. Connect a local MCP tool to Claude.ai

tunn mcp -- ./my-mcp-server

MCP endpoints are private by default. Copy the printed /mcp connector URL, sign in and approve access. Follow the complete tutorial.

Coming from ngrok?

# ngrok http 8080 →
tunn http 8080
# ngrok http 8080 --subdomain=work →
tunn http 8080 --subdomain=work

This is an HTTP command shortcut, not full ngrok compatibility. Run tunn login instead of configuring an ngrok authtoken. ngrok --domain, config files and traffic policies do not transfer. Free names are temporary; Pro attempts to reserve the first four published names, including random names. Choose names before publishing. Compare the tradeoffs.

Inspect webhooks and watch usage

tunn http 8080 --inspect
tunn usage

The local inspector omits bodies by default. Quotas apply across all account endpoints and reset monthly in UTC. Check your account or plans and exact usage units before upgrading. No automatic overage charges.
