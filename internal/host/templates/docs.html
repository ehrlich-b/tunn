Quickstart

Get online in 2 minutes

A private HTTPS URL for the app running on your machine.

You need macOS or Linux, a browser and a local app. Keep the app and tunn running while you use the URL.

1. Install and sign in

curl -fsSL https://tunn.to/install.sh | sh
tunn login

Approve the browser sign-in. Intel and ARM builds are supported. If your shell says tunn: command not found, add the install directory and try again:

export PATH="$HOME/.local/bin:$PATH"
tunn login

For pinned source builds or an interrupted install, see install and recovery. Containers have a Docker client guide.

2. Start a local app

Use your existing app on port 8080. Or serve an empty demo directory in a separate terminal:

mkdir -p /tmp/tunn-demo
python3 -m http.server 8080 --bind 127.0.0.1 --directory /tmp/tunn-demo

Open http://127.0.0.1:8080 first. If that fails, fix the local app before publishing.

3. Publish and open the URL

tunn http 8080

Open the HTTPS URL printed by tunn and sign in with the same account. You should see the same page as localhost. The endpoint is owner-only by default. Ctrl-C stops it; an offline URL cannot reach your app.

Choose who can connect. --allow=alice@example.com invites a verified email. --public permits anonymous requests; keep application authentication enabled. Webhook senders need public access and signature verification.
