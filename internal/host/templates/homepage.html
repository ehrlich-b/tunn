01 / HTTP

Expose localhost

Get an HTTPS URL for your local app or webhook handler.

tunn http 8080 --public

Use --public for webhooks; web tunnels default to owner-only. Verify sender signatures in your app.

HTTP quickstart →
02 / PEOPLE

Share with a person

Invite Alice by email. She opens the URL and signs in.

tunn 8080 --allow=alice@example.com

Private access in a plain browser. No tunn client for Alice.

Sharing guide →
03 / SSH

SSH with no client

Use your existing OpenSSH client to reach a shared machine.

ssh -J tunn@tunn.to:443 dev@my-ssh

After email/key enrollment. The publisher runs tunn; the origin still checks your SSH login. Requires the SSH front door.

SSH setup & pilot limits →
04 / MCP

Local tools to Claude

Paste your printed /mcp URL into Claude’s connector settings.

tunn mcp -- ./my-mcp-server

Private by default. Sign in and approve OAuth access to this endpoint.

MCP connector guide →
