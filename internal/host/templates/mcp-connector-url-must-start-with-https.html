Why does the Claude connector say “URL must start with https://”?

claude.ai needs a public HTTPS connector URL because connector requests come from Anthropic’s servers. A localhost address is not that public endpoint.

Connection routes include tunn, Cloudflare Tunnel, ngrok, hosting the server, and Anthropic’s MCP tunnels research preview. The choice depends on the endpoint and authentication setup.

A public address for the local server

The connector receives the public HTTPS URL, including the MCP path, rather than the local HTTP address. With tunn, the publisher copies the exact printed Connector URL, including /mcp.

Source: Connector testing documentation, accessed October 29, 2026.

Publish with tunn

The installation guide covers tunn setup. This example needs Python 3 and the echo example saved as echo.py in the working directory.

tunn login
tunn mcp --tools echo -- python3 ./echo.py

The publisher copies the printed Connector URL, including /mcp. MCP endpoints are private by default.

Local process and relay limits

The local MCP server and tunn process must keep running. Stdio calls must finish under 25 seconds and are serialized. TLS ends at the relay; the relay can read traffic.

The MCP connector walkthrough covers setup and verification. Pricing and plan limits apply to the account.
