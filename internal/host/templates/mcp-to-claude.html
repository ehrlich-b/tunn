Expose a local MCP server to Claude

Publish your local MCP endpoint, then use its connector URL in Claude.

Before you start, have tunn installed and a Streamable HTTP MCP server running at http://127.0.0.1:3000/mcp. Use a Claude account with custom connector access; organization accounts may need an owner to add the connector.

This is a short setup walkthrough, not a measured two-minute guarantee. tunn's OAuth connector flow is covered by local protocol tests. Live Claude interoperability has not been verified for this guide.

1. Install and sign in

curl -fsSL https://tunn.to/install.sh | sh
tunn mcp --help
tunn login

The help should show a <http-url> input. Complete the browser login prompted by tunn login.

2. Publish your local MCP server

tunn mcp http://127.0.0.1:3000/mcp

Use your server's actual port and path if they differ. The CLI prints a Connector URL ending in /mcp. Copy that exact URL, including the path. The endpoint is private by default; keep this process and your local server running.

If your existing server uses stdio instead, launch its executable through tunn:

tunn mcp -- ./my-mcp-server

Replace ./my-mcp-server with your server's executable and arguments. For a stdio server, --tools restricts which named tools tunn lists and permits callers to invoke:

tunn mcp --tools read_file,list_directory -- ./my-mcp-server

Use tool names your server actually provides. This flag applies to stdio servers; it does not filter an HTTP upstream.

3. Add the remote connector in Claude

  1. Open Claude's Customize → Connectors and add a custom connector. For an organization, an owner adds it through organization settings.
  2. Give it a name and paste the Connector URL printed by tunn.
  3. Review the detected authentication settings. Use OAuth sign-in and Register automatically for the OAuth client; tunn supports dynamic registration of public clients.
  4. Sign in to tunn in the browser and approve the connector's access to this tunnel.
  5. Finish adding the connector, then enable it for a conversation from the chat's connectors menu. Ask Claude to use one of your server's tools and check the result.

These UI steps follow Claude's custom connector guide, accessed October 11, 2026. Follow that guide if the UI changes. Claude makes remote connector requests from its cloud infrastructure.

Control access and disconnect

To let another verified tunn user approve a connector, restart the publisher with their email:

tunn mcp --allow colleague@example.com http://127.0.0.1:3000/mcp

At Connected MCP clients, the owner can disconnect a client for a tunnel. That revokes its current OAuth tokens and pending authorizations. OAuth tokens expire after one hour; this implementation does not issue refresh tokens, so a client may need to sign in again.

If connection fails

Check that the local server is running, the publisher is connected, the URL includes /mcp, and you sign in with the owner or an allowed email. HTTP upstreams must already implement MCP. The stdio bridge shares one child process across clients and does not implement stream resumption. See the connector protocol guide for the supported contract.
