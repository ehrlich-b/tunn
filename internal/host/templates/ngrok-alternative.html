An ngrok alternative for sharing localhost with email access

Use tunn to send someone a link to your local app and choose who can open it by email.

For a dev server already running on port 3000, install tunn and sign in once, then start a shared tunnel:

curl -fsSL https://tunn.to/install.sh | sh
tunn login
tunn 3000 --allow=alice@example.com

Replace the email with your teammate's verified address. Copy the HTTPS URL printed by the CLI. Your teammate opens it in a browser and signs in; the tunnel creator also has access. Keep tunn and the local server running.

Which workflow fits?

Consider tunn when you want to express a sharing rule in a CLI flag. Consider ngrok's documented Traffic Policy workflow when you want to compose authentication and request rules. Both provide visitor authentication; the table compares how you configure it.

Also expose local MCP tools

tunn can bridge a stdio MCP server or publish an existing HTTP MCP endpoint at /mcp. MCP endpoints require authentication by default. Follow the local MCP connector walkthrough or the OAuth sharing guide.
