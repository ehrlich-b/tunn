tunn 3000 --allow=alex@example.com

Alex opens the printed HTTPS URL and signs in with GitHub or an email link. Anyone else gets a 403 at the edge. Use --allow=@example.com for a whole domain and --public for webhooks.

Units differ: tunn counts admitted requests plus WebSocket and TCP opens, and transfer in both directions. ngrok counts HTTP requests and data out.

ngrok fits better if you need its gateway policies, compliance programs or an enterprise SLA; tunn publishes no SLA. Your laptop and tunn must stay online. See tunn plans · Connect a local MCP server · Share a dev server with OAuth
