How usage is counted

All endpoints share the account allowance. Admissions count HTTP and MCP requests, WebSocket opens and TCP opens. Transfer counts bodies, WebSocket wire frames and TCP payloads in both directions. TLS, HTTP and relay framing are excluded.

Allowances reset on the first day of each UTC calendar month. Upgrading raises the allowance without resetting usage. Streams can stop after response headers. Uploads are limited to 100 MiB; bandwidth and application limits still apply.

Reserved names

Free attempts to reserve {{.FreeReservations}} name; Pro attempts up to {{.Reservations}}. Use --subdomain before publishing. Random names use slots. Additional names are temporary at the limit. Unreserved names can be taken while offline. Contact support to change reservations.
