Quickstart / HTTP

Give port 3000 a URL.

Run your app on port 3000. Keep it running while you use tunn.

01Install tunn

macOS and Linux on Intel or ARM.

$curl -fsSL https://tunn.to/install.sh | sh

If tunn is not found, add $HOME/.local/bin to PATH. Install and recovery

02Sign in

$tunn login

Finish signing in in your browser. Return to the terminal.

03Open a public tunnel

$tunn http 3000 --public --inspect
https://demo.tunn.to → localhost:3000

Example URL. Use the URL printed by your terminal.

ⓘ
Public

Anyone with the link can open this app.

Leave out --public for owner-only access. Invite a person with --allow=alex@example.com; they sign in with that email.

04Send a request

Open your printed URL in a browser. View its method, path, result and time in the inspector.

Open web inspector

The web inspector stores redacted headers and request metadata. Bodies are not stored. Press Ctrl+C to stop the tunnel.

Verify webhook signatures before receiving real deliveries. Keep your app's signature checks enabled.
