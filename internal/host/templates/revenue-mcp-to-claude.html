Expose your local MCP server to Claude.ai

Your tools run locally. tunn supplies a private HTTPS /mcp endpoint and OAuth consent. Start with a harmless tool you can inspect.

Publish

tunn login
# stdio: tunn starts your server
tunn mcp -- ./my-mcp-server
# or forward an existing Streamable HTTP MCP server
tunn mcp http://127.0.0.1:3000/mcp

Use one of the two publication commands. For a small read-only example, get echo.py from the repository and run tunn mcp --tools echo -- python3 echo.py. The stdio bridge supports an exact --tools allow-list; HTTP upstreams enforce their own tool policy.

Connect

  1. Copy the exact printed Connector URL, including /mcp. Keep the terminal running.
  2. In Claude.ai, open Customize → Connectors → Add custom connector. Paste the URL. If OAuth client choices appear, choose automatic registration: tunn's preview implements dynamic client registration, not Claude's published client identity.
  3. Sign in to tunn as the owner (or an allowed email), review the tunnel and client, then approve access. Enable the connector in the conversation.
  4. Ask Claude to use the echo tool with “hello”. Review the tool call and expect an echo response. Revoke access at Connected MCP clients.

Team/Enterprise connector setup may require an owner. Availability and labels can change; Claude's connector instructions, fetched 2026-10-11, are the authority.

Keep the same URL

tunn mcp --name work-tools -- ./my-mcp-server

Free attempts to reserve one published name; Pro attempts up to ten, including random ones. Name endpoints deliberately before publishing. Names beyond the reservation allowance can be taken while offline. See Pro and quota limits.

Diagnose a failed connection

  • Claude connects from its cloud. localhost, a private VPN address or a stopped terminal cannot work as a connector URL.
  • A private endpoint's initial 401 with WWW-Authenticate and resource metadata is expected. Complete OAuth; do not switch to --public to bypass it.
  • Check /mcp, choose automatic OAuth registration, and sign in with an allowed email. For an HTTP target, tunn remaps public /mcp to your supplied path.
  • 429 with owner_request_budget or owner_byte_budget means an account quota; check tunn usage. 503 means the authority is unavailable; retry. MCP calls have a 27-second local timeout; keep tools short.
  • tunn handles connection/authentication and quotas, not your application's authorization rules. Limit writable tools and test with harmless data.

The current OpenAI quickstart uses Plugins → Add custom MCP server. Supply the same HTTPS /mcp URL and configure authentication, then install and invoke the plugin. Official OpenAI quickstart (fetched 2026-10-11). Account access and client compatibility need validation in your UI.
